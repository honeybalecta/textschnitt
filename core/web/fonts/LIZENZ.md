# Schriftarten

Alle Schriften stehen unter der SIL Open Font License 1.1 (OFL.txt) und stammen aus dem Google-Fonts-Archiv
(github.com/google/fonts). Für Textschnitt wurden aus den variablen Schriften feste Schnitte erzeugt und mit
„TS …“ umbenannt (so verlangt es die OFL für veränderte Fassungen).
